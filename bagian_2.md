1. Windows
•	Nama OS: Microsoft Windows
•	Fungsi OS: Sistem operasi untuk keperluan komputasi sehari-hari, perkantoran, hiburan, dan gaming di PC atau laptop. 
•	Kelebihan: Sangat ramah pengguna (user-friendly), mendukung paling banyak software maupun game, serta kompatibel dengan hampir semua perangkat keras (hardware). 
•	Kekurangan: Lisensinya berbayar dan cukup mahal, sistemnya tertutup (closed-source), serta paling rentan terkena virus atau peretasan. 
•	Perkembangan Singkat: Berawal dari sistem operasi MS-DOS yang hanya berbasis tulisan (teks), Windows berevolusi menambahkan antarmuka visual (GUI). Seri populernya membentang dari Windows 95, XP, 7, 10, hingga versi terbaru saat ini, Windows 11.
2. Linux 
•	Nama OS: Linux
•	Fungsi OS: Sistem operasi bebas yang banyak difokuskan untuk menjalankan komputer server, pengelolaan jaringan, dan pengembangan perangkat lunak (koding). 
•	Kelebihan: 100% gratis, bersifat sumber terbuka (open-source), sangat stabil, dan keamanannya sangat tinggi dari serangan virus. 
•	Kekurangan: Lebih sulit dipelajari oleh pemula (sering memakai perintah teks/terminal), ketersediaan software umum terbatas, dan kurang cocok untuk bermain game. 
•	Perkembangan Singkat: Diciptakan pertama kali oleh Linus Torvalds pada tahun 1991. Karena kodenya terbuka, OS ini berkembang pesat diolah oleh komunitas sedunia menjadi ratusan jenis (distro) seperti Ubuntu, Debian, dan Linux Mint.
3. macOS
•	Nama OS: macOS (sebelumnya bernama Mac OS X)
•	Fungsi OS: Sistem operasi eksklusif yang dirancang khusus untuk menjalankan perangkat komputer buatan Apple (seperti MacBook dan iMac), sangat populer untuk kebutuhan desain dan multimedia. 
•	Kelebihan: Tampilannya elegan, sangat lancar dan stabil untuk editing video atau gambar, aman dari malware, dan terhubung mulus dengan produk Apple lain (iPhone/iPad). 
•	Kekurangan: Perangkatnya sangat mahal, eksklusif (tidak bisa diinstal bebas di PC rakitan), dan software (terutama game) masih kalah lengkap dari Windows. 
•	Perkembangan Singkat: Berasal dari Mac OS Klasik di tahun 1984, Apple merombaknya pada tahun 2001 menjadi berbasis "Unix" (sistem yang jauh lebih aman). Namanya terus diperbarui dari OS X menjadi macOS hingga saat ini.
